| | 시나리오 A. 행사 모객·참석 관리 | 시나리오 B. 신규 장비 도입 90일 온보딩 |

## 시나리오 A. HCP 행사 모객·참석 관리

### 목적
- 행사 홍보부터 사후 팔로업까지 **같은 내용을 반복하지 않고 단계별로 다른 메시지**를 자동 발송
- **노쇼율 감소**(현재 평균 약 20%), **피드백 설문 회수율·만족도 향상**(현재 회수율 20~30%)
- 참석자는 다음 프로그램으로, 미참석자는 리마인드로 이어지게 해 **교육 지속성** 확보

### 대상
- 마케팅 수신 동의 HCP 중 행사 대상 세그먼트
  - 예) 뉴 유저 워크숍 → 신규 장비 HCP / 어드밴스드 트레이닝 → Tier 1·2, MTL·TTT / 간호사 교육 → 간호사·간호조무사

### 여정 흐름 (예시: 행사일 = D)

| 시점 | 대상 | 메시지 | 채널 |
|---|---|---|---|
| D-60 | 대상 세그먼트 전체 | 티저 — 행사 예고 | 카카오, 이메일 |
| D-45 | 〃 | Save the Date | 카카오 |
| D-30 | 〃 | 본 초청장 (웹 초청장 + **등록 CTA**) | 이메일, 카카오 |
| 등록 즉시 | 등록자 | 등록 확인 | 알림톡 |
| D-14 | **미등록자** | 연자·아젠다 소개 + 등록 리마인더 | 카카오, 이메일 |
| D-7 | **미등록자** | 마감 임박 리마인더 | 카카오 |
| D-3 | 등록자 | 참석 안내 (장소·시간·준비물) | 알림톡 |
| D-1 | 등록자 | 참석 리마인더 (**노쇼 방지**) | 알림톡, SMS(대체) |
| D+1 | **참석자** | 감사 인사 + **피드백 설문** | 알림톡, 이메일 |
| D+3 | 설문 미응답자 | 설문 리마인드 | 카카오 |
| D+7 | 참석자 | 강의 자료 공유 + **다음 단계 프로그램 안내** | 이메일 |
| D+7 | **불참자** (등록 후 미참석) | 자료 요약 + 다음 일정 안내 | 카카오 |

```
대상 세그먼트 → 티저 → Save the Date → 초청장(등록 CTA)
                                          ├─ 등록 → 확인 → 참석 안내 → D-1 리마인더 → 행사
                                          │                                    ├─ 참석 → 설문 → (미응답 리마인드) → 다음 프로그램 안내
                                          │                                    └─ 불참 → 자료 요약 + 다음 일정
                                          └─ 미등록 → 리마인더 2회 → (등록 시 위 흐름으로 합류)
```

### 필요 데이터

| 데이터 | 현재 위치 | 상태 |
|---|---|---|
| HCP 연락처·마케팅 수신 동의 | 홈페이지 DB | 있음 — Data Cloud 연동 필요 |
| 직군·세그먼트 (원장/간호사/실장, Tier, MTL·TTT) | 일부 Salesforce, 일부 수기 | 확인 필요 |
| 행사 정보 (행사명·일시·장소·대상) | — | 행사별 입력 방식 정의 필요 |
| 등록 여부 | — | **등록을 어디서 받을지 확인 필요** |
| 참석 여부 | 수기 | **현장 체크인 방식 확인 필요** |
| 설문 응답·점수 | 수기 | 설문 도구·연동 방식 확인 필요 |

### 성과 지표
- 초청 대비 등록률, 등록 시점 분포(하루 전 쏠림 완화 여부)
- **노쇼율**, **설문 회수율·만족도**
- 참석자의 다음 프로그램 등록률

### 확인이 필요한 사항
1. 행사 등록은 어디서 받으시나요? (홈페이지 폼 / 별도 등록 페이지 / 영업 담당자 취합)
2. 현장 참석 체크는 어떻게 하시나요? (QR, 명단 체크 등)
3. 피드백 설문은 지금 어떤 도구로 받으시나요?
4. 알림톡은 정보성 메시지(등록 확인·참석 안내)만 보낼 수 있습니다. 티저·초청장처럼 광고성 메시지는 친구톡·이메일로 보내야 하므로 채널 구분을 함께 확정해야 합니다
5. 행사마다 바뀌는 행사명·일시·장소를 **변수로 처리한 템플릿**으로 심의를 받으면, 행사마다 새로 심의받는 부담을 줄일 수 있는지 RA/QA 확인이 필요합니다

## 시나리오 B. 신규 장비 도입 HCP 90일 온보딩

### 목적
- 장비 도입 직후 사용법·교육 부족으로 생기는 **초기 이탈 방지**
- 도입 후 **첫 팁 재구매**까지 자연스럽게 연결
- 지금은 영업 담당자가 카톡·전화로 수기 팔로업하는 부분을 **Salesforce에서 구조화**(영업 담당자에게 팔로업 할 일 자동 생성)

### 대상
- 신규로 장비를 도입한 HCP (원장) — 마케팅 수신 동의 보유자

### 진입 조건
- Salesforce Install Base에 **신규 장비가 등록된 시점** (본사 출고 시 자동 등록)

### 여정 흐름 (예시: 장비 등록일 = D)

| 시점 | 메시지 | 목적 | 채널 |
|---|---|---|---|
| D+3 | 환영 인사 + 담당 영업사원·문의처 안내 | 관계 시작 | 알림톡 |
| D+7 | 장비 사용 가이드·시술 프로토콜 | 사용 정착 | 이메일, 카카오 |
| D+14 | **뉴 유저 워크숍** 초대 (→ 시나리오 A 연결) | 교육 참여 | 카카오, 이메일 |
| D+30 | 환자 상담용 콘텐츠·POSM 신청 안내 (**신청 CTA**) | 원내 활용 | 카카오 |
| D+45 | 임상 자료·백서 신청 안내 | 학술 신뢰 | 이메일 |
| D+60 | 체크인 — 사용 중 어려운 점 문의 | 이탈 신호 파악 | 카카오 |
| D+90 | 분기: 팁 미구매 → **영업 담당자에게 팔로업 할 일 생성** / 구매 → 900샷·아이팁 등 다음 단계 안내 | 첫 재구매 | Salesforce Task, 카카오 |

```
신규 장비 등록 → 환영 → 사용 가이드 → 뉴 유저 워크숍 초대 → 원내 활용 자료 → 임상 자료 → 체크인
                                                                                         └─ D+90 팁 구매 여부
                                                                                              ├─ 미구매 → 영업 담당자 팔로업 Task
                                                                                              └─ 구매 → 업셀·크로스셀 안내
```

### 필요 데이터

| 데이터 | 현재 위치 | 상태 |
|---|---|---|
| 신규 장비·시리얼·출고일·병원(Account) | Salesforce Install Base | **있음 — 자동 등록 중** |
| 원장 연락처 (Contact) | Salesforce | 있음 — 장비와의 연결 확인 필요 |
| 마케팅 수신 동의 | 홈페이지 DB | 있음 — **Salesforce 고객과 매칭 기준 필요** |
| 담당 영업사원 | Salesforce (Account 담당자) | 있음 — KR 담당자 정합성 확인 필요 |
| 워크숍 참석 여부 | 수기 | 시나리오 A와 함께 정의 |
| 팁 구매 이력 | 대리점 일 단위 엑셀 | **없음** — 없을 경우 D+90 분기 대신 영업 담당자 확인 Task로 대체 |

### 성과 지표
- 도입 후 90일 내 첫 팁 재구매율
- 뉴 유저 워크숍 참석률
- 콘텐츠 클릭·자료 신청 수
- 영업 담당자 팔로업 완료율

### 확인이 필요한 사항
1. 장비 출고일과 실제 설치 완료일 차이가 얼마나 되나요? (환영 메시지 시점 기준)
2. 월평균 신규 장비 도입 건수는 어느 정도인가요? (발송량·콘텐츠 우선순위 판단)
3. 신규 도입 원장의 마케팅 수신 동의는 언제, 어떻게 받으시나요? (설치·교육 시 현장 수집 가능 여부)
4. 팁 구매 이력을 Salesforce로 가져올 계획이 있나요? (대리점 엑셀 정기 업로드 등)

## 참고 — 그 밖의 후보 시나리오

| 후보 | 내용 | 고려사항 |
|---|---|---|
| 팁 리텐션·윈백 | 3~6개월 미구매(이탈 위험), 6개월 이상(휴면) 고객 재활성화 | 카피캣 대응으로 우선순위가 높지만, **병원별 팁 구매 데이터가 Salesforce에 없어** 데이터 확보 방안이 먼저 필요 |
| 업셀·크로스셀 | 600샷 → 900샷, 페이스 → 아이팁 | 팁 구매 이력 데이터 필요 (위와 동일) |
| 리드 너처링 | 리드폼 유입 → 7일 내 팔로업 → 상담·데모 연결 | 홈페이지 리드폼 데이터의 Data Cloud 연동 필요 |

> 3개 시나리오가 정해지면, 시나리오별 콘텐츠 수량과 심의 일정(약 3~4주)을 역산해 제작 일정을 공유드리겠습니다.
