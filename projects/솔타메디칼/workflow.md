## 작업별 처리 방식
### 현업 인터뷰
1. 시나리오 중심 질문지 작성 (마케팅 대상·원하는 시나리오·혜택·필요 데이터 유무)
2. 내부 리뷰 (30분)
3. 인터뷰 진행 (녹화)
4. 정리: 질문별 답변 → 결정사항 → 리스크(R#) 갱신 → 후속 자료 요청(M#)
5. 회의록 게시(Partha CC) + history 기록

### 회의록
- 내부공유용(한국어) 먼저 작성 → 글로벌 게시용 영문본 (확인)
- 구조: 개요표 / 참석자 / 논의 / 결정사항 / 액션아이템(담당·기한) / 내부 논의
- 파일: `meetings/YYYY-MM-DD-제목.md`

## 자동 처리 허용

- 산출물·회의록 '초안' 작성 (`docs/`·`meetings/`에 초안으로 저장)
