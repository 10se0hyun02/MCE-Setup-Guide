## 2. MCE(Marketing Cloud Engagement)란?

Salesforce가 제공하는 **기업용 이메일 마케팅 + 마케팅 자동화 플랫폼**입니다.

일반 이메일 서비스와 달리 MCE는 다음을 지원합니다.

- **대량 발송**: 수십만 명에게 개인화된 이메일을 동시 발송
- **전달률 관리**: 전용 IP + 인증 도메인으로 스팸 분류 방지
- **자동 여정**: "기부 완료 → 3일 후 감사 메일 → 30일 후 리마인드" 같은 흐름 자동화
- **성과 측정**: 오픈율·클릭율·이탈율 실시간 리포트

초록우산 운영에서는 주로 **이메일 발송**, **Journey(자동 여정) 관리**, **데이터 동기화**, **성과 보고**가 핵심 업무입니다.

---

## 3. MCE 주요 앱 — 운영에서 자주 쓰는 것

MCE는 용도별로 여러 앱으로 구성되어 있습니다. 운영 중 실제로 접하게 되는 앱 위주로 정리합니다.

| 앱 | 하는 일 | 언제 쓰나 |
|---|---|---|
| **Email Studio** | 이메일 발송, 구독자 관리, 수신거부 처리, 발송 성과 확인 | 발송 직전·직후, 이슈 처리 |
| **Content Builder** | 이메일 템플릿·이미지·HTML 블록 제작 및 라이브러리 관리 | 발송물 제작·수정 |
| **Journey Builder** | 고객 행동 기반 자동 이메일 여정 설계·운영 | 자동화 캠페인 모니터링·수정 |
| **Automation Studio** | SQL 쿼리로 세그먼트 생성, FTP 데이터 가져오기, 정기 배치 자동화 | 데이터 동기화·정기 처리 |
| **CloudPages** | 수신거부 페이지·구독 페이지·랜딩 페이지 운영 | 수신거부 처리, 캠페인 랜딩 |
| **Analytics Builder** | 발송 성과 리포트 및 대시보드 | 주간·월간 보고 |

## 4. 핵심 용어

처음 접하면 낯선 약어들입니다.

| 약어 | 설명 |
|------|------|
| **BU (Business Unit)** | MCE의 독립 운영 단위. Parent BU(관리용)와 Child BU(실제 발송)로 나뉨 |
| **DE (Data Extension)** | 구독자·발송 데이터를 담는 테이블. MCE에서 DB 테이블과 동일한 개념 |
| **SAP** | 전용 발신 도메인 + 전용 IP + DKIM 인증을 묶은 패키지. 도달률에 직결됨 |
| **IP Warming** | 신규 전용 IP의 발신 신뢰도를 쌓기 위해 소량부터 점진적으로 발송량을 늘리는 과정 |
| **Send Classification** | Commercial(마케팅)과 Transactional(주문확인·OTP)의 법적 구분. Transactional은 수신거부자에게도 발송 가능 |
| **AMPscript** | MCE 전용 스크립팅 언어. 이메일 안에서 이름·기부금액 등 개인화에 사용 |
| **FTP (Enhanced FTP)** | 고객사 DB → MCE로 구독자 파일을 올리는 파일 서버 |
| **Bounce** | 이메일 발송 실패. Hard Bounce(영구 오류, 주소 없음)와 Soft Bounce(일시 오류, 수신함 가득 참) 구분 |
| **AS** | Automation Studio 약칭 |
| **JB** | Journey Builder 약칭 |

## 5. 운영 담당자의 주요 업무

### 상시 모니터링
- 캠페인·Journey 발송 성과 확인 (오픈율·클릭율·이탈율·스팸 신고)
- Automation Studio 스케줄 오류 점검
- Journey Builder 흐름 이상 점검
- DE 데이터 동기화 상태 확인

### 캠페인 지원
- 고객사 요청 이메일 발송 (단발성 캠페인 실행)
- Content Builder에서 템플릿 수정·신규 제작
- 발송 전 테스트 발송 및 렌더링 검수 (주요 클라이언트 기준)

### 이슈 대응
- 발송 실패·Bounce 급증 원인 파악 및 처리
- 수신거부 요청 접수 및 반영 확인
- IP 평판 모니터링
- 고객사 문의 대응 및 에러 리포트 작성

### 보고
- 주간/월간 발송 성과 보고서 작성
- 고객사 보고 자료 준비 (Analytics Builder 데이터 기반)
